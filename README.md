# 台股每日條件篩選平台

## 網路版（建議）
網址：https://mikaylagao.github.io/tw-stock-screener/
- 手機用瀏覽器開啟後「加入主畫面」即可當 App 使用，不需開電腦。
- GitHub Actions 於台灣時間週一至週五 16:40、18:40、21:10 自動抓官方資料並更新網站（可查最近 60 個交易日）。
- 手動更新：GitHub 儲存庫 → Actions → 「每日更新與部署」→ Run workflow（可填日期重抓單日）。

## 本機版使用
1. 雙擊 `啟動篩選平台.bat`（需已安裝 Python 3，使用 `py` 啟動），瀏覽器會開啟 http://localhost:8765
2. 每個交易日收盤後（建議 16:00 以後，投信資料約 15:00 後公布）按「更新資料」。
   - 會從最後已存日期接續抓到今天，並更新處置公告、重新計算全部指標。
   - 首次使用會從 2026/04/01 回補歷史（MACD 起點同原平台），約 20–30 分鐘。
3. 也可用命令列：`py fetch.py`、`py fetch.py --refetch 20261105`（重抓單日）。

## 手機使用（放到手機桌面）
1. 電腦執行 `啟動篩選平台.bat`，視窗會顯示「手機請開啟：http://192.168.x.x:8765」（電腦網頁底部也會顯示）。
   - 第一次啟動 Windows 可能跳出防火牆詢問，請允許「私人網路」。
2. 手機連同一個 Wi‑Fi，用瀏覽器開啟該網址。
3. 放到桌面：
   - iPhone（Safari）：分享 → 加入主畫面
   - Android（Chrome）：右上 ⋮ → 加到主畫面
4. 手機版：上方左右滑動切換策略；下方「篩選・排序」開啟篩選面板；點卡片看完整數據；「匯出」可直接分享 CSV。
5. 限制：電腦需開著且伺服器在執行、手機需在同一個 Wi‑Fi。只想在本機使用可改執行 `py server.py --local-only`。

## 檔案
- `fetch.py`：抓取證交所／櫃買中心每日行情、投信買賣超、處置公告 → `data/daily/YYYYMMDD.json`、`data/disposal.json`
- `engine.py`：計算所有指標與條件（三態：成立／不成立／未判定）
- `server.py`：本機伺服器與 API
- `web/index.html`：篩選介面（自訂組合存在瀏覽器 localStorage）

## 規則摘要
- 只納入代號為 4 碼數字的一般股票（排除 ETF、權證、特別股）。
- 「前一交易日」= 資料庫中前一個有開市的交易日。
- 收盤漲停：上櫃用櫃買中心前一日公告的「次日漲停價」；上市用（收盤 − 漲跌價差）得出當日參考價 ×1.1，依升降單位無條件捨去。新股上市前 5 日無漲跌幅限制，可能誤判。
- MACD(12,26,9)、未還原收盤價、EMA 以 SMA 初始化、柱體 = 2×(DIF−DEA)、零軸容差 1e-8、需 ≥120 筆。
- 下一交易日出關：處置迄日 = t，且截至 t 未公告再次處置／延長；t 當日無成交 → 待核對。
- 資料缺漏一律為「未判定」，不計入不成立。
- 「前次符合日」：所選日期之前最近一次符合同一策略的交易日（原平台「最近符合日」定義未公開，此為暫定）。
